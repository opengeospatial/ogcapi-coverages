===== Coverage JSON representation

[[req_coveragejson_coverage]]
[requirement]
====
[%metadata]
identifier:: /req/coveragejson/coverage
part:: If a particular collection is suitable for a CoverageJSON representation, the coverage resource as defined in the Coverages API Core requirements class SHALL support negotiating a https://docs.ogc.org/cs/21-069r2/21-069r2.html[CoverageJSON] response using the `application/vnd.cov+json` media type.
part:: The response SHALL be a CoverageJSON document which validates against the CoverageJSON community standard.
====
