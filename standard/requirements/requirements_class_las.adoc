===== LAS representation

[[req_las_coverage]]
[requirement]
====
[%metadata]
identifier:: /req/las/coverage
part:: If a particular collection such as point cloud is suitable for a LAS representation, the coverage resource as defined in the Coverages API Core requirements class SHALL support negotiating a https://docs.ogc.org/cs/17-030r1/17-030r1.pdf[LAS] response using the `application/vnd.las` media type.
part:: The response SHALL be a LAS point cloud which validates against the OGC LAS Community Standard, using a Point Data Record Format suitable for the data being returned.
====
